# Regra Obrigatória: Sempre Commitar Alterações

Neste projeto, toda implementação, melhoria, refatoração ou correção de bugs concluída **DEVE ser imediatamente commitada no Git** (`git add` e `git commit -m "..."`).

- NUNCA deixe alterações pendentes no working tree ao finalizar um pedido do usuário.
- Garanta mensagens de commit claras e descritivas seguindo conventional commits.
- Isso previne perda de trabalho entre sessões e garante que o histórico e o Expo Bundler estejam sempre na versão mais recente.
